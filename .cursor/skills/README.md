# 项目 Skills（openclaw-Comtrade-Code）

改编自 `E:\downloadskills\skills-main`（[mattpocock/skills](https://github.com/mattpocock/skills)），用于 Cursor Agent 在本仓库内的工作流。

| Skill | 用途 |
|-------|------|
| `grill-with-docs` | 大改前对齐需求，更新 CONTEXT / ADR |
| `improve-codebase-architecture` | 找浅模块、耦合点，对照 CONTEXT 与 ADR |
| `zoom-out` | 不熟悉代码时画模块关系图 |
| `git-guardrails` | 提醒禁止危险 git 操作 |

安装到 Cursor：将本目录链接或复制到项目 `.cursor/skills/`，或在 Cursor 设置中启用项目 skills。
