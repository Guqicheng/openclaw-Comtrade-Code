## 1. CAAP2008X 包结构判断

| 观察项 | 结论 |
|---|---|
| 主程序 | `CAAP2008X.exe`，约 1.7 MB |
| UI 框架 | Qt4：`QtCore4.dll`、`QtGui4.dll`、`QtNetwork4.dll` |
| 业务 DLL | `AnaCMTD.dll`、`ZHRECtoCMTD.dll`，推测分别负责录波分析/格式转换相关能力 |
| 文档 | `CAAP2008X.pdf`，约 5.96 MB，提供功能目录、公式函数、导出/图形/分析线索 |
| 样本数据 | 随包包含多组 DRL600A/DRL600B COMTRADE 样本 |
| 体积基准 | 你本机 CAAP 目录约 24 MB（含文档、Qt4 DLL、样本） |

结论：CAAP2008X 是一个**桌面端专业波形分析工具**，业务重点不是“只读 COMTRADE 文件”，而是围绕录波文件完成浏览、测量、频域、相量、序分量、功率、阻抗、导出和报告等完整分析闭环。

## 2. CAAP2008X 核心业务拆分

### 2.1 业务主线

| 业务阶段 | CAAP 可能的核心逻辑 | 项目一当前对应 |
|---|---|---|
| 文件接入 | 读取 COMTRADE/扩展格式；解析元信息、采样率、通道、触发点 | `.cfg + .dat` 上传、解析、返回 `analysisId` |
| 波形显示 | 多通道波形展示、模拟/开关量区分、缩放、光标、触发点 | Plotly 多子图、缩放联动、双光标、触发点基础标注 |
| 基础测量 | RMS、峰谷、光标差值、相角差 | 已实现 RMS、峰谷、双光标、相角差 |
| 频域分析 | DFT/FFT、谐波、滤波、频率估计 | 已实现 FFT、1~15 次谐波、THD；滤波/频率估计未完整 |
| 三相/相量 | 相量、序分量、ABC/ABCN 相关分析 | 相角差已实现；相量图/序分量缺失 |
| 功率/阻抗 | P/Q/S、R-X、距离保护相关分析 | 缺失 |
| 对比分析 | 波形叠加、多文件/多通道对比、X-Y 图 | 多子图已有；叠加/X-Y/多文件对比缺失 |
| 输出交付 | PNG、CSV/Excel、报告、可能的 CAAP 专用格式 | 缺失导出 PNG/CSV/报告 |
| 工具/公式 | 文档中出现大量公式函数：`rms`、`dft_*`、`seq_*`、`power_*`、`rx_*` 等 | 项目一目前不是公式引擎，只有固定分析 API |

### 2.2 从 PDF 可见的功能线索

> PDF 文本抽取存在乱码和目录缺字，因此这里只记录较可靠的英文/函数/格式线索。

| 线索 | 推断出的 CAAP 能力 |
|---|---|
| `COMTRADE1999`、`COMTRADE1991` | 支持多版本 COMTRADE |
| `DFT`、`dft_m`、`dft_a`、`dft_r`、`dft_x` | 频域分析不仅是 FFT 图，还可能支持幅值/相角/实部/虚部分解 |
| `harm_e`、`harm_m`、`harm_a`、`harm_r`、`harm_x` | 谐波相关计算更完整，可能含有效值、幅值、相角、实部、虚部 |
| `flt_hamm`、`flt_diff` | 滤波/微分等信号处理能力 |
| `seq_e`、`seq_m`、`seq_a`、`seq_r`、`seq_x` | 序分量分析（正序/负序/零序或序分量实/虚/幅/角） |
| `power_p`、`power_q`、`power_s` | 有功/无功/视在功率 |
| `rx_m`、`rx_a`、`rx_r`、`rx_x`、`rxk_*` | 阻抗/距离保护相关 R-X 分析 |
| `mkwave_*` | 构造/派生波形能力 |
| `phsd(c1,c2)` | 相位差/相角差 |
| `X-Y` | X-Y 图或轨迹图 |
| `.png`、`CSV`、`EXCEL` | 图像与数据导出 |
| `ABC`、`ABCN` | 三相/三相四线相关分析入口或配置 |
| `T0` | 触发点/基准时间相关操作 |
| `1MHz` | 高采样率/大数据读取能力线索 |

## 5. 建议的功能取舍

### 5.1 必须尽快补齐（P0）

| 功能 | 原因 | 验收标准 |
|---|---|---|
| 触发点标注完善 | 录波分析最基础的时间基准 | 上传后所有子图显示触发线；可开关；标注时间 |
| 波形叠加对比 | CAAP 类软件基础对比能力 | 选多个模拟通道，在同一坐标系叠加显示 |
| 导出 PNG | 分析结果需要给别人看 | 导出当前视图，含触发点/光标/标注 |
| 导出 CSV | 分析结果需要二次处理 | 导出 t + 选中通道数据；支持全量/当前视窗 |

### 5.2 重要但可以后置（P1）

| 功能 | 原因 | 备注 |
|---|---|---|
| 相量图 | 从“看波形”进入“电力专业分析” | 可复用相角差/FFT 基波结果 |
| 序分量 | 三相保护/故障分析核心 | 需通道命名/选择规则 |
| 功率 P/Q/S | 变压器/线路分析常用 | 需 U/I 通道配对 |
| 阻抗 R-X / X-Y 图 | 距离保护分析核心 | 可先做通用 X-Y 图，再做保护专用 |
| 谐波相角/实虚分量 | 对齐 CAAP `harm_*`/`dft_*` 能力 | 目前只展示频率/幅值/占比 |

### 5.3 可以先舍弃或长期观察（P2/P3）

| 功能 | 建议 | 原因 |
|---|---|---|
| 完整公式引擎 | 暂不做 | CAAP 有大量函数，但实现成本高，先做固定专业分析更稳 |
| 报告生成 | 后置 | 需要先稳定图形/导出/分析结果 |
| 多文件对比 | 后置 | 当前先做好单文件专业分析 |
| 录波回放动画 | 后置 | 展示价值有，但不是核心分析闭环 |
| 体积瘦身 | 收尾做 | 先完成功能，发布前裁剪依赖/资源 |

## 8. 当前结论

项目一已经具备 CAAP2008X 的**基础读取与基础测量能力**：上传、波形、多子图、缩放、双光标、RMS、峰谷、FFT/谐波、相角差。

但与 CAAP2008X 的专业分析能力相比，项目一仍缺少三类关键能力：

1. **输出交付能力**：PNG、CSV/Excel、报告。
2. **对比分析能力**：波形叠加、多文件/多通道对比、X-Y 图。
3. **电力专业分析能力**：相量图、序分量、功率、阻抗轨迹。

因此，下一步建议继续按 M2 P0 推进：**触发点标注完善 → 波形叠加对比 → PNG 导出 → CSV 导出**。
