## 二、功能对标 CAAP2008X 路线图

```
目标：达到 CAAP2008X 基础操作级的可用性
估算：2-3 天
```

| 功能 | 说明 | 工作量 |

| **触发点标注** | 在波形上标记触发时间位置，竖线+标注 | 半天 |
| **波形叠加对比** | 同一图内叠加显示多个通道，方便对比 | 1 天 |
| **导出截图** | 当前波形视图导出为 PNG 图片 | 半天 |

## 三、UI 布局参数

```
顶栏高度: 40px
侧栏宽度: 280px（可折叠为 0）
底栏高度: 28px

子图布局:
  左边距(l): 55px（y轴标题区）
  右边距(r): 8px
  上边距(t): 22px（C1/C2标注区）
  下边距(b): 4px
  子图间距(wrapper): 1px
  总间隙: 4+1+22 = 27px

每页子图数: 3/4/5 可切换
降采样上限: 8000 点（2K 屏 2560px × 3 倍余量）
```

## 四、版本与分支策略

```
main        ← 稳定发布版（手动合并）
  └─ dev    ← 日常开发（所有改动在此）
       └─ fix/*    ← 临时修复分支（修复后合并到 dev 后删除）

版本命名: v1.3.x.y
  x: 新增功能时递增（如 1.3.1, 1.3.2）
  y: 修 Bug 或小优化时递增（如 1.3.0.1, 1.3.0.2）

发版流程:
  开发完成 → git tag v1.3.1
         → git checkout main
         → git merge dev
         → git push origin main --tags
         → git checkout dev
```
